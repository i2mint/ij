ij.converters.text_to_ir

Text to DiagramIR converters.

This module provides simple rule-based conversion from structured text to DiagramIR. Future versions can integrate AI/LLM-based conversion.

Simple rule-based text to diagram converter.

Parses structured text like: - “Start -> Process A -> Decision B” - “If condition: Process C, else: Process D”
