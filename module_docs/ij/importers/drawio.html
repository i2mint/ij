ij.importers.drawio.from_drawio(file_path: str, page: int = 0) → DiagramIR[source]

Import diagram from draw.io file.

Parameters:

  • file_path – Path to draw.io (.drawio or .xml) file

  • page – Page number to import (0-indexed)

Returns:

DiagramIR representation

Example

>>> diagram = from_drawio('flowchart.drawio')

Note

draw.io files use compressed XML. This provides basic support for flowchart elements.
